# NBA Player & Team Analysis

## Overview
SQL-driven analysis of 18,000+ NBA player seasons from 1980-2018
using SQLite and Python.

## Questions Explored
1. Which players had the highest scoring seasons in NBA history?
2. How has NBA playstyle changed over time?
3. Which teams consistently produce the highest scoring players?

## Key Findings
- Michael Jordan's 1987 season (37.09 PPG) remains the highest 
  scoring season in modern NBA history
- 3-point attempts increased nearly 8x from 1980 to 2018, while 
  average FG% dropped from 48% to 43% — teams trade efficiency 
  for the higher value of the 3-point shot
- Houston and OKC lead team scoring systems, while Golden State's 
  system distributes scoring across the roster rather than 
  concentrating it on stars

## Tools Used
- Python (pandas, matplotlib)
- SQLite
- Jupyter Notebook
